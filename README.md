# Data Analysis Portfolio

This repository showcases three applied data analysis projects. Each notebook demonstrates skills in **data cleaning, exploration, visualization, hypothesis testing, and deriving insights** — the core competencies of an entry-level Data Analyst.  

## 📂 Projects

### 1. Visualization of Trends
📓 [Visualisation_completed.ipynb](./Visualisation_completed.ipynb)  
- **Goal**: Explore dataset patterns through descriptive statistics and visualizations.  
- **Highlights**:  
  - Distribution analysis (prices, ratings, reviews).  
  - Neighborhood/location impact on demand.  
  - Seasonal variation in booking/review activity.  
- **Key Takeaway**: Demand is concentrated in specific areas and seasons, with opportunities to improve guest experience and pricing strategy.  

---

### 2. Hypothesis Testing
📓 [hypothesis_testing_completed.ipynb](./hypothesis_testing_completed.ipynb)  
- **Goal**: Apply hypothesis testing to evaluate whether group differences in the dataset are statistically significant.  
- **Highlights**:  
  - Group comparisons (e.g., customer segments, genders, or regions).  
  - p-value interpretation and decision-making.  
  - Balance between statistically significant and non-significant results.  
- **Key Takeaway**: Only a subset of observed differences were statistically significant, guiding where targeted strategies are most valuable.  

---

### 3. Gathering Insights
📓 [gathering_insight_completed.ipynb](./gathering_insight_completed.ipynb)  
- **Goal**: Use exploratory analysis to uncover hidden patterns and correlations.  
- **Highlights**:  
  - Outlier detection and handling.  
  - Correlation analysis to identify drivers.  
  - Visualization of seasonal or temporal trends.  
- **Key Takeaway**: Strong correlations and seasonal patterns provide actionable insights, but further testing and richer data sources are recommended.
